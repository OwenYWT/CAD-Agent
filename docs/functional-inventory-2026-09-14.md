“已接入”表示有实际实现及调用入口；每项的适用范围写在说明中。验收范围以文末报告为准，本次文档整理未重新执行全套业务测试，也未重新探测所有外部服务。

| 标记 | 含义 |
| --- | --- |
| 已接入 | 已进入当前产品或后台运行链路 |
| 受限 | 已实现部分范围，限制见说明 |
| 接口 | 后端可调用，当前主界面没有完整入口 |
| 可选 | 有适配实现，使用前需要相应依赖、凭据或设备 |
