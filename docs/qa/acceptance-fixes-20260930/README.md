- 材料层缺损、错误孔径及不可证明的几何仍然不能通过必需检查。

- 未改数据库 schema、模型选择、输出 token 上限、请求或建模等待时间；未删除用户数据。
- 径向证书仍明确限定圆柱侧壁，不声称证明端盖、任意复杂曲面或全部 FreeCAD 能力。
- 真实工作流测试使用受控需求/视觉提供者与真实 FreeCAD、Temporal、PostgreSQL、MinIO；不代表在线大模型自由建模成功率。本轮不花费额外模型 token 重跑评测集。
