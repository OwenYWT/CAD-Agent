## 实现调用链与兼容性

1. 原需求/规划 → `operation_compiler` / `operation_generator` → `edge_intent` → `FeatureChamferArgs` → FreeCAD runner → BRep 范围解析与受保护孔壁检查 → 候选工件 → 独立最终实体/STEP 对比 → 接受、提交。
2. `config.make_llm_client` → `llm_composition` → 显式 Sink 参数 → Provider 适配器 → 真实用量持久化。失败观测不得覆盖 Provider 结果；没有新增输出 token 上限或调用总时限。
3. REST/工作流输入共享纯 DTO；旧 Temporal 导出保留兼容。旧 chamfer 未设置 edge_scope 时序列化字节结构不变，不重写历史 hash；旧 use_all_edges 仍表示全部边，新“外边”请求不能生成该模式。
4. CI → 各实际套件 → 必需报告校验 → regression-gate。CODEOWNERS/汇总 Gate 在分支保护未生效时，仍不能阻止拥有权限的人直推。
5. 未改业务状态机、Head 提交条件、租户授权或 schema；当前 schema 为 `0030_model_job_json_numbers`。

## 审查与限制

- 复核关注功能域 01、05–08、10、12、14–16、19、24；检查候选与当前版本、幂等键、归属、最终几何、回放及权限链路。
- 风险扫描提示的生产 `pass` 是异常类型声明；测试中的 `pass` 是明确断言拒绝后的捕获分支，不是假成功。固定历史及测试受控响应有明确标识。扫描还包含测试团队未跟踪报告，这些文件未改写、不纳入本次提交。
- 只读交叉复核发现 TS 别名/后缀绕回旧门面的遗漏；已退出审查阶段修复，再次复核 17 条门禁测试通过。审查阶段仅写审查知识/报告。
- outer 的自动选边当前保守支持外表面为支撑平面、可带内圆柱孔的单实体；不支持/不明确的曲面、凹边界明确拒绝并要求显式选择。不是任意曲面的外边识别，也不是手机壳适配验证。
- 架构门禁覆盖静态可解析导入，不承诺识别任意反射、运行时字符串或 SQL 隐式依赖；后者依赖行为回归。609 条例外是待治理债务，不能作为“零耦合”依据。
- 最新腾讯云只读 SSH 复查出现连接关闭；本轮此前观测到约 2 GB 内存、约 3.4 GB 空闲磁盘。没有在缺少余量及最终发布身份时直接升级线上来冒充隔离验收。
- 结论不等于第二位人类审核者批准。独立几何算法、旧发布回放、不同版本进程及浏览器/数据库交叉取证提供技术交叉验证；F02 要求的独立人工审查仍需另行完成。
