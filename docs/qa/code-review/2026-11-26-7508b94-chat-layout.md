## 产品界面

打开工作台即可描述零件，最近对话和历史项目在左侧。提交后，需求依据、任务进度和结果随对话出现，底部输入框支持继续修改。已有原生文件也能从输入区导入。模型卡可以展开，查看属性、检查、版本、导出及项目流程。桌面与窄屏共用实际修订和已加载场景。

## 发现与验收边界

- 初次布局隐藏了需求依据、空对话改名和部分专业入口，展开模型时还会重建画布。修正后在原版和新版用同一模型重复验证，候选、选择、相机和版本均可追溯。
- 扫描提示的 placeholder 均为真实输入控件的提示文字、类型或样式。其余 fixture 命中属于测试新建的数据、取数断言及其证据标识。运行期审阅需要实际持久化状态，未发现编码损坏、固定成功值或伪造后端结果。详见对话记录、数据库状态及文件哈希。
- 两个真实编辑对照中，原版与新版针对同一文档的业务请求字段哈希分别完全相等。规划器曾提出尺寸语义冲突或越出已选特征的导出范围，服务端拒绝执行，零候选。网络亦出现过模型服务 TLS 握手中断。失败均另列。清楚指定保留默认导出范围后，针对已选特征的实际修改、保存与几何核验成功。没有改动这些服务端约束。
- 同输入建模的额外 A/B 环境把已有的模型网络重试设置为 5；两版一致。默认重试配置也独立走通。初次额外环境的基础镜像仅 Python 证书依赖版本与基线有差异，正式 A/B 及独立重开所用 FreeCAD 镜像与 46 个受控输入完全一致。
- 237 项逐项对照中，149 项有实测证据，31 项覆盖部分场景，41 项核对代码与合同，16 项需外部条件。仓库的服务集成组按原始条件跳过 9 个付费专项，另行执行的真实浏览器、模型与内核测试通过。实机打印、实际物理强度或密封、真实短信投递、Onshape、Fusion 桌面及 Autodesk APS 的生产账户操作均未做实物或生产验收。Bridge 验证了真实 CLI 重启及租约过期，本轮未重启 API 进程。自动化测试的控制输入、真实产品运行和未执行的条件门分别统计。
- 11 月 26 日的功能复核在隔离账户、数据库、对象桶和工作流队列中完成。生产发布在此后单独执行。
- 11 月 27 日的发布回归发现新版首页缺少原有的顶栏设置入口。恢复入口后，真实浏览器在 320、390、768 和 1440 像素宽度下均能打开 DFM 设置。原有草稿回读用例的八个场景通过，包含写入回执丢失后的核对和显式重试。[首次发布回归记录](https://github.com/OwenYWT/CAD-Agent/actions/runs/45855079213)
