## 验证结果

- 前端全部 152 项测试通过；ESLint 无错误、无警告；TypeScript 与 Vite 构建通过。
- 后端使用仓库 CI 配置运行：1453 项通过、159 项跳过、1 项排除。

### 真实调用链与浏览器验证

使用本地真实 API、WebSocket、PostgreSQL、Temporal、模型服务、CAD 内核及 Artifact 服务。没有替换网络响应或伪造业务成功。原生参数测试的初始板件由真实 FreeCAD 执行测试夹具生成。

1. **明确尺寸首次生成**：100×60×3 mm 板从自动摘要提交，依据进入持久任务，实际建模、候选审查、应用并保存；下载 STL 测得包围尺寸为 **100、60、3 mm**，SHA-256 与服务端一致。
2. **编辑摘要后生成**：在摘要将厚度 3 改成 4 mm，提交目标和尺寸依据随之更新；实际保存模型测得 **100、60、4 mm**，没有继续使用原始 3 mm。
3. **原生参数闭环**：Hole.Diameter 从 **6 改为 6.5 mm**，原位确认计划、真实计算、原位打开候选审查并应用；文档成为 v2，输入框自动解锁并读回 6.5。其他参数保持不变，FCStd、状态和网格的 SHA-256 全部核对一致。
4. **取消与拒绝**：修改为 7 mm 后拒绝执行计划；另一次修改为 7.1 mm 后拒绝真实生成的候选。两次均保留输入、恢复编辑，原已保存版本不变，新请求使用不同任务 ID。
5. **选择与布局**：真实网格单击保持 Agent，选择同步到树；双击打开属性。所有抽屉共用右侧区域，Canvas 保持，布局切换前后相机画面一致。覆盖 1440、1181、1024、900、760、390、320 px。
6. **版本与相机**：以精细精度从当前模型查看旧模型版本，再回到当前版本；Canvas 对象不变、精度仍为精细、往返画面像素一致，回程未重复下载缓存网格。适应视图未重建 Canvas，也未重新请求网格。
7. **移动端**：无模型的真实失败任务默认可见；切到模型后可通过错误提示返回处理。真实候选同样可由移动端任务提示返回 Agent。
8. **需求边界**：普通板件无需尺寸来源表单或概念勾选；缺尺寸仍阻止未经确认执行；手机壳仍显示适配未验证并要求补依据或明确概念确认。

## 边界与发布状态

- 本轮没有实现新的面／边拾取和原生拓扑映射；做的是准确表述现有粒度及保留树选特征路径。
- 尺寸提取是保守规则，覆盖常见毫米／厘米几何表达，不等于通用工程需求理解或实物适配验证。复杂、含糊需求仍需补充或确认执行计划。
- 真实浏览器覆盖取消计划和拒绝候选；失败状态恢复另有单元覆盖，本轮未人为制造 CAD 内核崩溃。
- 自动化跳过的外部服务／环境依赖测试不计作通过；本轮没有重验每一种 FEA、CAM、Fusion 或其他外部连接器。
- 既有装配规划／BOM 问题不属于本轮界面验收修复，不声称已解决。
- 本轮改动和报告在本地工作区，**尚未推送 GitHub 或部署腾讯云**。工作区原有 `code_gen.py`、相关修复测试和 `docs/development.md` 的未提交改动未并入本次范围；用户的 `.superpowers/` 未修改。
