# 模型优先执行页：实现与验收报告

## 本次范围

按确认方案调整执行页的信息组织，复用现有任务状态、云文档、参数提交、候选审阅和导出接口。未增加依赖，未修改数据库结构或建模算法。

## 已实现

- 默认三栏：左侧项目、线程与历史；中央 CAD；右侧 Agent。项目导航和 Agent 可以收起，右栏可以拖动或用键盘调整宽度。
- 顶部属性、检查、版本、导出打开同一个右侧区域，替换 Agent，不增加第四栏。抽屉保留任务状态和返回 Agent；Escape 可关闭，移动端抽屉管理键盘焦点。
- Agent 默认显示用户需求、当前任务及步骤、关键错误和下一步操作。条件与尺寸依据、计划、执行记录、检查证据、历史对话和需求示例默认折叠。缺乏尺寸依据时仍显式标注适配未验证。
- 选中真实原生模型对象会打开属性，并沿用现有对象标识同步特征树与 Agent 修改目标。特征说明、文档元数据和内部标识收进详情。
- 原生参数与旧模型参数使用统一属性入口。右栏切换保留编辑草稿；原生参数仍使用既有租约、基线校验、排队和候选审核。只读版本和权限不足时不可提交。
- 检查沿用真实证据查询与运行入口；版本沿用历史浏览、恢复、候选审查。分支与发布放在版本中的折叠区。
- 文档、共享、工程计算、代码、文件和 BOM 位于更多工具。BOM 只在打开对应工具时读取，Onshape 发布也需展开后才读取服务配置。
- 导出可用性由当前查看版本的实际产物与权限共同决定。没有文件时禁用；没有导出权限时服务端继续拒绝受保护产物请求。
- CAD 视口不随抽屉切换重新挂载。版本状态在模型区使用简短名称，详细版本标识可展开查看。
- 修复页面高度被内容撑开导致输入框移出屏幕，以及窄屏标题挤出顶部操作按钮的问题。320–1440 px 保留四个工程入口，移动端可在模型和 Agent 间切换。

## 边界与未完成项

- 本次复用既有原生场景的对象映射。没有独立部件网格的特征仍提示无法单独高亮；未新增任意面、边和孔壁的拓扑拾取。不能将部件联动声称为所有拓扑对象均可定位。
- 视图重排不能证明手机壳实物适配、制造条件或尺寸来源可靠；相关未验证提示保留。
- 此前电子盒装配任务的本地完整测试仍在 BOM 阶段失败：`bom_input_missing`。该任务不是本次页面验收的成功案例，规划器/修复链路的未完成工作单独保留，不随页面发布声称已解决。
- FEA、CAM、Onshape 等低频能力的原有入口保留。本轮没有调用外部 Onshape 发布或重新验证全部工程求解器。
