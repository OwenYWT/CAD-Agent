## 确认的原因与修改

| 问题 | 实际证据 | 修复 |
| --- | --- | --- |
| 盒体被误分为装配体 | 需求卡附加说明包含“开孔与装配依据”，Planner 的关键词规则据此覆盖模型已经返回的语义分类；一体盒被拆为底板和侧壁 | 去除关键词强制覆盖，保留经过校验的结构化分类；保留用户明确要求的装配体 |
| 薄壁抽壳失败 | 原沙箱中，60×40×25 盒体先加 2 mm 圆角再向内抽壳 2 mm，实际抛出空消息的 `Standard_ConstructionError` | 优先外实体减内腔，保留指定尺寸，不擅自加圆角或减薄壁厚；空异常消息保留真实异常类型 |
| 等模型被强制停止 | 原任务的 DFM 修复连续三次在约 305 秒被 Temporal 活动截止打断 | 新 V2 模型调用改为数据库持久化任务，由后台 Worker 执行；工作流等结果，无模型生成总等待期限 |
| 错误卡显示过期失败 | 工作流最终是 `Activity task timed out`，投影却选择此前已修复的 CAD 步骤错误 | 最终错误以工作流为准；只有同一错误才附带步骤详情；终态关闭未完成步骤并撤销执行租约 |
| 几何与 DFM 判断相反 | 同一真实 STEP/STL，几何通过而 DFM 认为不封闭 | 两者使用相同顶点合并和重复/退化三角形清理；不补洞、不替换模型、不跳过制造检查 |
| 隔板位置漏算原点 | 新回归中，外框从 (10,10) 起，隔板却使用未加偏移的 y=19，导致两个腔室宽度不等 | 明确所有草图共享 XY 原点，内部特征坐标只加一次原点偏移；补充居中隔板和等分净空的计算规则，随后重新生成验证 |

模型任务通过租约心跳检测 Worker 故障，通过 generation 防止旧 Worker 写回，使用原租户和原提交账号记录用量。主动取消会关闭实际模型连接。工作流轮换轮询历史，但不重新生成模型。

Temporal 短控制活动的期限只覆盖数据库入队、查询和取消，不包裹模型调用。CAD 沙箱计算资源限制、依赖健康检查和旧工作流回放兼容逻辑保留。取消 SDK 等待和取消工作流对模型的等待截止是不同层面的修改，本次补齐后者。
