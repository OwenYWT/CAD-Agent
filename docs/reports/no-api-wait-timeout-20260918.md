# 取消模型 API 等待超时

日期：2026-09-18。

## 修改范围

- 统一模型客户端显式传入 `timeout=None`，覆盖 Moonshot、OpenAI 兼容服务和 Azure。不是省略参数后继承 SDK 默认超时。
- 统一调用适配器同时覆盖单次请求的 `timeout`，避免局部调用重新引入等待期限。
- 删除 `LLM_TIMEOUT_S` 配置字段和环境变量示例。旧部署中遗留的同名变量被忽略。
- 删除 FreeCAD 操作生成的 120 秒单次调用覆盖值。
- 超时错误文案不再声称“超过 60 秒”，也不再建议调整已移除的配置。
- 保留实际网络错误、有限重试、流式完整性检查、取消与账号用量记录。等待中不会产生伪造的完成结果。

## 范围边界

本次取消的是模型 API 客户端的连接、读取、写入和连接池等待超时，包括首段响应与流式数据间隔。

未修改 Temporal 活动执行期限：当前 V2 普通活动 5 分钟，指定 FreeCAD 模型活动 20 分钟；执行活动按沙箱预算另算。旧生成入口的管线期限、CAD 沙箱计算期限、心跳检测以及外部服务自身限制继续存在。因此不能宣称整个建模任务没有时间限制。

## 验证

- 相关模块测试：100 项通过。
- 后端回归：1465 项通过，164 项跳过，1 项排除。跳过部分不视为已验证。
- 实际本地 HTTP 连接长等待测试：2 项通过，耗时 130.48 秒。分别验证非流式在响应头前等待 65 秒、流式在响应头后连续 65 秒没有数据，均正常读取结果；单次调用传入的 0.01 秒旧覆盖值未生效。
- 实际 HTTP 连接取消测试：流式与非流式等待均可被取消，连接关闭。
- 三种服务客户端底层 HTTP 超时全部为 `None`，旧环境变量无法重新启用等待时限。
- 长等待测试使用明确标注的本地协议测试服务，不作为真实模型生成成功的证据。
