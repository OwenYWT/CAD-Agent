# CAD 状态数值传递修复与验收

日期：2026-09-19。原任务：`79ebe664-a5c2-41b4-91d8-849d82b2232b`。

## 根因与修复范围

原任务在 `model_jobs.submit` 计算操作输入指纹时失败，尚未调用修改操作生成器或执行 FreeCAD。真实错误为 `IntegerDomainError`；外层只呈现了 `Child Workflow execution failed`。

原模型的 `App::Line`、`App::Plane` 是无界参考几何。其可视化形状被统一测量后产生 `4e100` 等数值；原始状态文件中是浮点数，经模型任务结果的 JSONB 存取后变成超大整数，违反 RFC 8785 的整数精度要求。同一问题也存在于步骤重放读取的 JSONB 事件中。

| 环节 | 修改 |
| --- | --- |
| 原生状态投影 | 按 FreeCAD 原生基准类型标记无界轴／面，不读取其物理长度、面积、包围盒和质心。保留名称、类型、属性、位置变换、依赖、BREP 指纹。未按名称或数值大小过滤对象。 |
| 历史模型 | 验证原始产物哈希后，在内存中适配旧状态；不重写原 FCStd、状态文件或历史版本。历史检查接口也明确返回 `not_applicable`，不把无界长度当作实际测量。 |
| 模型任务持久化 | 迁移 `0030_model_job_json_numbers` 将仅承载执行数据的 payload/result/error 改为保留原始数字表示的 PostgreSQL `json`，写入端同步使用 `json`。原角色、隔离策略、索引、租约与幂等机制保持原逻辑。 |
| 步骤重放 | 查询用事件仍保留 JSONB 投影，额外保存原始结果 JSON 文本；执行重放从该文本恢复，避免重启后再次改变数字类型。旧事件的基准几何在内存中兼容处理。 |
| 指纹与诊断 | 保持 RFC 8785 规则，不将所有整数转换成浮点数；不合法整数的异常增加字段路径。 |
| 工作流错误 | 遍历 Temporal 子流程与活动的异常链，提取底层应用错误。最终错误记录通过版本补丁兼容旧工作流回放。 |
| 空形状兼容 | 空几何不导出 BREP，保持旧投影行为，避免尚未生成形状的特征受影响。 |

没有新增模型等待期限、输出 Token 限额或任意尺寸上限；没有把极大数截断或替换成零。普通实体及大数浮点值不因大小而被删改。
