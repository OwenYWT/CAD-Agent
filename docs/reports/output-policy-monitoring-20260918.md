# 输出策略与独立账号监控交付报告

日期：2026-09-18。已部署腾讯云，保留现有 CAD 前端及原有账号、文档和版本。

## 本次完成

### 取消应用输出上限

- 全部 16 个模型调用点移除输出 Token 参数，覆盖需求、装配、多步骤规划、代码生成、修改、修复、FreeCAD 操作、视觉检查及 Fusion 规划。
- 统一适配器过滤 `max_tokens`、`max_completion_tokens`、`max_output_tokens`，包括旧调用者和 `extra_body` 中的同名参数，防止局部旧代码再次设置上限。
- 删除 `PLANNER_MAX_TOKENS` 配置字段与示例；部署中遗留同名环境变量不再生效。
- 使用已有流式适配器接收完整结果并请求真实 usage；去掉应用的流式字符数上限。断流、空结果和服务截断仍明确失败，装配代码不再通过补括号把截断结果当作完整代码。
- 继续保留网络超时、任务执行期限、取消和结果校验。应用不设置输出预算，不代表模型服务可以无限输出。

### 独立监控面板

入口：**https://www.wordswave.ai/monitor/**。

- 独立 FastAPI 进程、容器和页面，CAD 工作界面不增加入口。
- 复用现有平台管理员 `admin`；普通项目 owner/editor 无权读取监控 API，不提升测试账号权限。
- 按日期和账号汇总任务数、成功、失败、处理中、取消、模型调用数、失败/截断次数、输入/输出/总 Token、未知用量次数、平均调用耗时和最近使用时间。
- 任务与模型调用分别查询，支持按账号筛选、分页和详情。详情包含任务 ID、服务、模型、阶段、重试次数、响应 ID、错误类型与 HTTP 状态。
- 用 `llm_calls` 持久化每次实际调用及重试，开始和结束分别写入。Temporal 拦截器关联真实提交账号、工作区、任务和活动，异步上下文结束后恢复，避免串号。
- 同一账号的多个工作区合并统计；账号名优先取其个人身份，避免共享工作区别名覆盖登录账号。
- 服务未返回用量时保存 NULL、显示“未知”；仅累计已知 Token。推理 Token 不重复加到总量。历史调用用量不补造，也不估算费用。
- 不记录密码、API Key、完整需求正文、模型回复或原始错误正文。请求和回复仅记录哈希。
- 管理员读取使用独立数据库角色及只读事务；该角色不能读取账号密码、任务需求正文或写入数据。

使用与运维说明：[monitoring.md](../monitoring.md)。管理员登录信息保存在本机私有文件 `~/.local/share/cad-agent/monitoring-access.md`，权限 0600，未写入仓库。
