## 2026-09-13 联调结果

同一模型经自然语言生成、HTTP Ø8、浏览器 Ø9 手改后，真实 Provider 将 Pad 从 16 mm 改到 18 mm；FCStd/STEP 独立测量孔位、孔径、深度和体积一致，原特征 ID 保留。真实多孔消歧、两侧分支 ABA、受限草图、4.5 mm 不可能圆角、恢复 ACK 丢失及接受后 commit 传输失败均已验证。

宿主常规回归 1,413 passed；后续正式 Python 3.11 镜像补跑为 1,416 passed / 155 skipped，包含 Node 依赖策略的新增分支和镜像中可执行的两项 Chroma 测试。前端 113 passed，PG 集成 108 passed，Temporal 控制回归 20 passed，原生运行时 4 passed。跳过项单独记录。四个实际 Workflow 历史 replay 通过；联合恢复在新数据库/存储桶核验 69 表、10,437 行、609 对象及 16 个历史原生修订，认证在当前配置中实际使用 PostgreSQL。

发布和 Bridge 完整回归通过，包括实际 305 s 租约过期、14 文件交付、API 地址变化后的代理重连、不安全本地目录失败与修复后新交付。Bridge 两次因共享 PostgreSQL 连接耗尽失败，保留失败记录后改用本轮专用 PG 实例，浏览器复验页面/控制台错误均为 0。原共享数据库保留。

正式 Dockerfile 的后端、前端、沙箱构建和运行时探测通过；`http://127.0.0.1:8101/` 是无源码挂载的正式镜像验证环境，空数据库迁移至 0027、真实原生创建和浏览器手改/刷新/审查提交/文件哈希通过。主开发验收入口仍为 `http://127.0.0.1:8100/`。
