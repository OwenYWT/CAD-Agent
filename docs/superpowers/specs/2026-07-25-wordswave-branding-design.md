# WordsWave 品牌替换设计

## 目标

将前端所有面向用户的 `CAD Agent` 品牌统一为 `WordsWave`，并使用用户提供的方形 logo 替换现有字母 `C` 图标。品牌调整应融入当前克制、浅色的工程工作区，不改变任何业务流程、接口或数据结构。

## 设计

- 将 `/Users/wentao/Desktop/Owen/wordswave_logo.jpg` 原样复制为 `frontend/src/assets/wordswave-logo.jpg`，由 Vite 纳入构建产物，并将同一资源配置为 favicon。
- 新建单一 `BrandMark` 组件，统一处理 logo、品牌名称、尺寸、间距、加载失败回退和无障碍文本。组件提供“带名称”和“仅 logo”两种明确模式：
  - 带名称时显示 logo 与可见的 `WordsWave` 文本，图片使用空 `alt`，避免读屏重复朗读。
  - 仅 logo 时，交互容器提供 `WordsWave` 可访问名称；图片加载失败则显示尺寸不变的字母 `W` 占位。
- 首屏左上角显示小尺寸 logo 与 `WordsWave`。
- 登录页显示 logo 与 `WordsWave`，保留原有登录层级和表单布局。
- 项目工作区左上角仅用 logo 替换现有字母图标，旁边继续显示项目名称，避免将产品名称与项目名称混淆。
- 浏览器标题和其他面向用户的 `CAD Agent` 文案统一改为 `WordsWave`。

原图接近正方形（1267 × 1280），使用 `object-contain` 完整展示、轻微圆角、无额外阴影；默认尺寸为 28px，登录页使用 36px。首屏品牌名使用 16px，登录页使用 22px。带名称模式下图片加载失败不影响 `WordsWave` 文本；仅 logo 模式使用 `W` 占位，不改变 Header 尺寸。

## 第二轮视觉微调

- 首屏、项目工作区和登录页的 logo 与 `WordsWave` 按统一比例放大，增强品牌识别，但不增加 Header 高度。

- 删除项目流程页的“默认只展示项目阶段和下一步。工程模型、参数、检查和文件会在进入对应工作区后展开。”。

## 非目标

- 不修改后端接口、数据库、鉴权、WebSocket 或工程任务逻辑。
- 不重新设计整体配色、排版或页面结构。
- “所有品牌位置”只包括前端渲染文案、浏览器标题、favicon 及相关视觉资源。不批量重命名仓库、API 名称、存储键、环境变量、代码标识、技术日志或历史文档中的技术名称。
